# Parroquia San Juan Bosco — San Martín

Primera versión funcional de una PWA parroquial.

## Qué incluye
- Inicio móvil
- Agenda
- Horarios de Misa
- Comunidades
- Catequesis
- Cáritas
- Noticias
- Oración y Evangelio
- Contacto
- Instalación como app
- Funcionamiento básico sin conexión gracias al Service Worker

## Publicarla en GitHub Pages
1. Crear un repositorio nuevo en GitHub.
2. Subir todos los archivos de esta carpeta a la raíz del repositorio.
3. Ir a Settings > Pages.
4. Elegir Deploy from a branch.
5. Seleccionar la rama `main` y carpeta `/root`.
6. Guardar y abrir la dirección que GitHub indique.
